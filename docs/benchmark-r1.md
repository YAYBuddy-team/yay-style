# Бенчмарк примерки без генеративного ИИ — прогон r1

*29.10.2026.*

Оценка в этом отчёте **предварительная**. Её поставил ИИ (Claude) по уменьшенным
контактным листам, а не слепо. Окончательное решение — после вашей слепой оценки:
http://localhost:5173/bench.html?run=r1&tab=rate

## Что проверяли

- **50 вещей с WB:** 20 верха, 12 низа, 10 платьев, 8 верхней одежды. Отобраны случайно
  из 163 найденных карточек одежды; детская одежда исключена.
- **10 «пользователей»:** фото моделей с WB в полный рост, из других товаров. 8 женщин,
  2 мужчин. Сложные случаи взяты специально: plus-size, селфи в зеркале с телефоном,
  руки на бёдрах, руки в карманах, длинное платье, оверсайз.
- **478 пар.** Платья и юбки на мужских фото не примерялись. Настройки по умолчанию,
  без ручной правки.
- **Вопрос оценщику:** «Можно ли по картинке понять, как вещь будет смотреться, и решить, брать или нет?»

## Результат (предварительный)

| Категория | Приемлемо | |
|---|---|---|
| **Верх** | 91 / 200 | **46 %** — ниже порога 50 % |
| Низ | 70 / 118 | 59 % |
| Платья | 55 / 80 | 69 % |
| Верхняя одежда | 59 / 80 | 74 % |
| **Всего** | 275 / 478 | **57,5 %** |

**По типу фото вещи:**
- на модели — 62 %;
- без модели, на фоне (flat-lay) — 47 %;
- «нет годного фото» — 10 пар, все неудачные.

**По «пользователю»:** от 82 % (облегающее платье) до 46–49 % (свободная одежда,
plus-size, руки в карманах).

## Почему верх ниже порога: две независимые причины

### 1. Подготовка вещи (проблема бэкенда)

7 из 20 вещей верха проваливаются почти у всех: от 0 до 2 удачных отрисовок из 10.
Это около 66 из 109 неудач по верху.

| Вещь | Причина |
|---|---|
| Футболка (flat-lay), фон в цвет вещи | Удаление фона «съело» части вещи |
| Футболка (flat-lay) на карточке с надписями | То же |
| Белый свитшот на светлом фоне | Вырезался только принт |
| Корсет | В вырезку попали чёрные брюки модели: одного цвета с верхом |
| Футболка, на фото 2 человека | Попал рукав второй модели |
| Блузка с принтованными рукавами | Рукава отрезал фильтр по палитре. **Исправлено после прогона** |
| Блузка с пышными рукавами, модель в шаге | Поза: рука вынесена вперёд |

Тот же тип проблем есть и в других категориях:
- платье с лишним куском ткани;
- леггинсы, у которых вырезалась одна нога;
- шуба;
- **плавательный жилет, ошибочно попавший в верхнюю одежду** (баг категорий, исправлено).

**Если бы эти 7 вещей подготавливались правильно,** верх на остальных 13 вещах дал бы
67 % (87 из 130).

### 2. Своя одежда пользователя (фундаментальное ограничение без ИИ)

Без генеративной модели нельзя «стереть» то, что на человеке надето. Если своя одежда
шире или длиннее примеряемой, она торчит из-под неё:
- длинные рукава под футболкой;
- оверсайз шире новой вещи;
- длинное платье под брюками.

| Одежда на фото пользователя | Верх приемлемо |
|---|---|
| Облегающая или короткая (u01, u03, u04, u05, u07) | 55 % |
| Свободная, с длинным рукавом, оверсайз (u02, u06, u08, u10) | 34 % |

Отдельная проблема — **plus-size (u02).** Ширина вещи берётся по суставам плеч и бёдер,
а не по силуэту тела, поэтому вещь выходит уже фигуры.

## Чего этот прогон не показывает

- **Это не фото реальных пользователей.** Здесь профессиональные снимки моделей:
  хороший свет, ровная поза. На домашних фото результат, скорее всего, будет хуже.
- **Оценка не слепая и сделана по превью.** Мелкие артефакты могли проскочить как
  «приемлемо».
- **Ручная правка не использовалась.** В приложении пользователь может подвинуть и
  растянуть вещь.

## Варианты решения (по плану: точка решения)

1. **Сузить MVP и починить подготовку вещей**, оставаясь без ИИ:
   - **Подготовка вещей:** брать только фото на модели; честно отвечать «эту вещь
     примерить нельзя», если годного фото нет; ширину вещи брать по силуэту тела.
   - **Требования к фото пользователя:** жёсткий онбординг — облегающая одежда, проверка
     этого при загрузке.
   - **Оценка:** верх для «правильных» фото — порядка 60–70 %. Платья, верхняя одежда и
     низ уже около порога или выше.
2. **Раньше подключить ИИ-режим для верха:** self-hosted FASHN VTON v1.5 (Apache-2.0) на
   GPU. Генеративная модель решает обе причины: рисует вещь поверх любой одежды и сама
   справляется с фоном. Но это стоимость GPU и отказ от «бесплатно и на устройстве» для
   этой функции.
3. **Гибрид:** вариант 1 как основной бесплатный режим, ИИ — как платный «реалистичный»
   режим. Этот путь и так был в плане, вопрос только в сроках.

## Исправлено по итогам (прогон r1 сделан до исправлений)

- Фильтр по палитре больше не трогает рукава.
- «Плавательные / спасательные жилеты» и утяжелители не считаются одеждой.

## Как повторить

1. Запустить API с `YAY_DEV_MODE=1`. Конфигурация `api` в `.claude/launch.json` уже это
   делает.
2. Открыть http://localhost:5173/bench.html?tab=run&run=r2 и нажать «Запустить прогон».
3. Слепая оценка — на вкладке «Слепая оценка», итоги — на вкладке «Итоги».

Где лежат данные:
- набор: `services/data/bench/garments.json` и `services/data/bench/persons/`;
- отрисовки и оценки: `services/data/bench/runs/<run>/`.
