# Бенчмарк r2 — после сужения MVP (без генеративного ИИ)

*29.10.2026. Как и в r1, оценка **предварительная** (ИИ, не слепая, по контактным листам).
Слепая оценка: http://localhost:5173/bench.html?run=r2&tab=rate*

## Что изменилось после r1

1. **Только фото на модели** для товаров с маркетплейса. Если такого фото нет — честный
   отказ «примерка недоступна». Вручную фото без модели выбрать можно.
2. **Строже отбор кадра:** боковой ракурс, вид со спины и вещь, обрезанная кадром, больше
   не выбираются автоматически (порог 0,5).
3. **Несколько людей в кадре** — фото отбраковывается.
4. **Ширина вещи по силуэту.** Бэкенд меряет у модели ширину тела на уровне груди, талии и
   бёдер, браузер — то же у пользователя. Корпус вещи расширяется там, где пользователь
   относительно шире. Это помогает при фигуре plus-size и при своей свободной одежде.
5. **Исправления:** фильтр палитры больше не отрезает рукава; плавательный жилет
   больше не считается одеждой (в наборе заменён на косуху).
6. **Предупреждения на фото пользователя:** «длинные рукава будут видны» (отдельно
   проверяется и «руки на теле / в карманах», см. ниже).

## Результат (предварительный)

Охват — 39 из 50 вещей (78 %). У остальных 11 вещей нет годного фото на модели:
- верх — 13 из 20;
- низ — 8 из 12;
- платья — 10 из 10;
- верхняя одежда — 8 из 8.

| Категория | Среди примеренных | Те же пары: r1 → r2 | Все пары, отказ = «нет» |
|---|---|---|---|
| **Верх** | **78 / 130 = 60 %** ✅ | 52 % → 60 % | 39 % |
| Низ | 49 / 78 = 63 % | 59 % → 63 % | 42 % |
| Платья | 51 / 80 = 64 % | 69 % → 64 % | 64 % |
| Верхняя одежда | 67 / 80 = 84 % | 84 % → 81 % | 84 % |
| **Всего** | **245 / 368 = 67 %** | 64 % → 66 % | 51 % |

**Порог решения (≥ 50 % для верха) пройден среди вещей, которые мы беремся примерять.**

**Верх по «пользователям»:** 8–9 из 13 у всех, кроме двух:
- руки в карманах (u08) — 3 из 13;
- оверсайз-футболка (u10) — 5 из 13.

Разница ±4–5 п.п. между прогонами укладывается в шум оценки одним оценщиком.
Например, у платьев 69 % → 64 %: на 80 парах это 4 картинки.

## Что осталось

- **Четыре вещи верха проваливаются почти у всех:** блузка с пышными рукавами, футболка с
  флажком от соседнего кадра, футболка с белым «лоскутом», корсет. Проверка «несколько
  людей» пропустила одну из них. Следующий шаг — ещё раз разобрать эти кадры.
- **Руки на теле или в карманах.** Кисти рисуются поверх вещи и выглядят как дыры.
  Добавлено предупреждение по коже кистей внутри контура корпуса: на наборе оно верно
  сработало на u08 и не сработало ложно на остальных 9 фото.
- **Длинная юбка под брюками.** Детектор пробовал, но он путал широкие брюки с юбкой
  (2 ложных из 3), поэтому убран. Пользователь узнает об этом по картинке.
- **Своя оверсайз-одежда:** расширение корпуса помогает, но широкие рукава всё равно видны.

## Вывод

Сужение сработало. Внутри MVP (вещи с фото на модели) примерка без ИИ даёт около
60–65 % приемлемых результатов по всем категориям, верхняя одежда — выше 80 %.

Цена — охват 78 % вещей и требования к фото пользователя:
- облегающая одежда;
- руки вдоль тела.

Окончательно подтвердить цифры должна ваша слепая оценка. И главное, что пока не
проверено, — **фото реальных пользователей**: домашний свет, телефонная камера, зеркало.
